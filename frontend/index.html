Comprehensive Accessibility Rule Engine

Images & Media

Detects missing alt attributes, unlabelled image buttons, decorative image misuse, and uncaptioned video tracks.

Forms & Inputs

Validates label associations (for/id, wrapping), empty labels, accessible names on buttons, and autocomplete opportunities.

Headings & Landmarks

Enforces single H1 presence, identifies heading level skips (e.g. H1 to H3), empty headers, and validates main landmarks.

ARIA & Interactive

Catches critical focus traps like aria-hidden="true" on focusable elements, empty aria-labels, and custom button tabindex.

How It Works

1. Submit Markup

Paste raw HTML into the code editor or upload an HTML file using the safe FileReader API without executing script tags.

2. DOM Analysis

The client-side DOMParser constructs a live DOM tree and passes it through 10 modular JavaScript rule analyzers.

3. Score & Report

Deductions are calculated based on severity (Critical: 15, Error: 8, Warning: 3, Info: 1) producing an actionable visual report.

4. Save History

Save audit snapshots and detailed issues into MySQL via Flask REST APIs to track accessibility improvements over time.
